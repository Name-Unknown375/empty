Bluff exposure adds elevation-driven wind on top of coastal wind. The most-rated install hardware in our kit applies here. We schedule install windows around forecast — bluff installs sometimes happen earlier in the November window before weather narrows safe-install conditions.

Established residential further inland from Marine Drive. Less direct coastal wind exposure but still meaningful afternoon thermal patterns. Standard wind-rated clip hardware on the rooflines; mini-light accents work well in sheltered tree zones. $8.50–$10/ft pricing.

### Uptown and South Surrey-border

Mid-density residential with mature trees and standard urban-character rooflines. Most run the Starter or Classic package — warm-white C9 along the main roofline with optional tree accents.
