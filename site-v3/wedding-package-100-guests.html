Wedding Package FAQs

Can I customize what's in a wedding package?
Absolutely. The package is a starting point — add linens, dance floor, heaters, or upgrade chairs before checkout. Anything you add keeps the 10% package discount on the original bundle; add-ons are at standard rates.
What if my guest count changes after I book?
We'll adjust to the next package tier if it fits — no repricing surprises. If you're between sizes (e.g., 75 guests), we recommend the 100-guest package so you have the right tent footprint and enough chair spares.
Does the wedding package include delivery and setup?
Delivery and professional setup are available as an add-on across all tiers — included in every quote we send. Pickup from our warehouse is also available with the same 10% package discount applied.
