We're a small enough team that the person who quotes your install is on the roof during install day. We're large enough that we own every part of the service — design, install, maintenance, takedown, storage — and don't sub-contract.

On the truck for a typical Richmond install:

- **Warm white C9 LED roofline** (the most-booked Richmond aesthetic)
- **Wind-rated install hardware** for Steveston-area properties
- **Clip-style install** — no staples, no nails, no trim damage on heritage homes
- **WCB coverage and roof certification** for two- and three-storey buildings
- **Commercial install crews** for after-hours building access at Olympic Oval-area properties

> Steveston wind isn't optional. We rate the install for it before quoting, not after the first storm.

## Richmond's two install rhythms

### Steveston Heritage and Garry Point residential

Heritage homes with detailed trim and complex rooflines, plus newer Garry Point-area residential blocks all sit on Strait of Georgia exposure. Sustained-wind-rated install hardware is the default; we use commercial-grade LED strands rather than delicate mini-lights on exposed rooflines. Most heritage installs run the Classic or Premium package given the linear footage of detailed roofline trim.

### Olympic Oval and Brighouse commercial

Storefront facades, restaurant exteriors, hotel buildings, plaza entrances around the Olympic Oval and Brighouse corridor. Commercial installs need building-management coordination on access windows; we book the install slot and confirm permit-or-bylaw considerations during quoting. Most commercial installs run on warm-white C9 or alternating-pattern designs.

### Seafair, Hamilton, and Thompson residential

Single-family detached homes with the standard residential install pattern. Most lots accept the Starter or Classic package — warm-white C9 along the main roofline with optional tree and bush accents. Pricing lands in the $8.50–$10/ft range for most.

### Cultural-event commercial

Richmond's cultural-event venues (community centres, large temples, festival-organizing properties) sometimes book Christmas-light installs that overlap with cultural celebrations through the December timeframe. These installs run on event-specific timing — install completes before the cultural calendar kicks off.

Year one, you pay for design, install, lights, takedown, and storage as a fixed package. Year two, the math gets meaningfully better — your strands are already in our warehouse, labeled with your roof's section map. The install crew arrives on day one with the same lights, the same plan, and the same install pattern. Most Richmond clients see year-2 pricing 15–25% lower than year-1 because the materials are already paid for.

For Steveston-area properties especially, the wind-rated commercial-grade LEDs are the largest year-one materials cost — and they're already in storage for year two.

## A typical Richmond residential install

For a two-storey Steveston-area home with rooflines, two front-yard trees, and a pathway from the sidewalk to the door, a typical Classic package install looks like:

- ~150 linear feet of warm-white C9 LED along the main and gable rooflines
- ~80 linear feet of mini-lights wrapping the two front-yard trees (sheltered side of the property)
- ~30 linear feet of pathway lights along the front walk
- Wind-rated clip-style attachment for the exposed sides
- One on-site design walk-through, season-long maintenance, January takedown, free storage

Setup runs 4–6 hours; takedown 2–3 hours. Both quoted up front. The Premium package adds bush wraps and architectural accents.
