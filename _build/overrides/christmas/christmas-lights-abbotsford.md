## Abbotsford install patterns

### Sumas Mountain-facing acreages

Single-family rural-residential properties with significant elevation exposure to the Fraser Valley afternoon thermal pattern. Sustained-wind-rated install hardware is the default; sidewall lighting on porches handles wind cleanly through the season. Most run the Premium package given the linear footage and the wind-rating requirements.

### Matsqui, McKee, Aldergrove-border rural-residential

Acreage properties without the same elevation exposure as Sumas-facing but still well outside urban-density sheltering. Standard wind-rated clip hardware on the rooflines; mini-light accents in sheltered tree zones. Pricing $9–$11/ft.

### Mill Lake and central Abbotsford residential

Mid-density residential in the older neighborhoods around Mill Lake and central Abbotsford. Most run the Classic package — warm-white C9 along the rooflines plus accent strands on porches and front-yard trees. $8.50–$10/ft pricing.

### Clayburn Village heritage

Historic homes with detailed trim and protected sightlines. Heritage-friendly clip-style installs (no staples, no nails). Smaller-scale installs given the village footprint; most run the Classic package.

### Tradex and Highway 1 commercial

Convention centre, retail plazas, restaurants along the Highway 1 commercial corridor. Commercial installs need building-management coordination on access; we book after-5pm or weekend install timing.
