## Langley's install patterns

### Vineyard and estate properties

Township 7, Domaine de Chaberton, and the smaller agritourism estates often book multi-building installs — primary residence plus tasting-room exterior plus outbuilding accent lighting. Vineyard installs typically run $9–$12/ft given the multi-building coordination and access constraints. We schedule install windows around the venue's tasting-room calendar where relevant.

### Brookswood and Murrayville acreages

Single-family rural-residential properties with extended rooflines, multiple outbuildings, and significant front-of-house landscape. Most acreages need 200–400 linear feet of roofline plus tree and pathway accents. Pricing lands in the $8.50–$10/ft range for typical Premium-package installs.

### Walnut Grove and Willoughby residential

Modern subdivision residential with simpler rooflines than rural-acreage properties. Most accept the Starter or Classic package — warm-white C9 along the main roofline with optional tree accents. $8.50/ft pricing for most Starter installs.

### Heritage and downtown Langley

Historic homes and downtown commercial properties with detailed trim and access constraints (narrow alleys, heritage-protected sightlines). Most heritage installs run the Classic package given the linear footage and the clip-style install required.
