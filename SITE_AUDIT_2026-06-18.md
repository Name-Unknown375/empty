## Executive Synthesis

### Lead-auditor synthesis

## 1. Executive Summary

The site is structurally sound and largely well-built (a real webp/preload pipeline exists, schema is mostly correct, copy is mostly authentic), but the audit surfaced **three high-severity issues that warrant action before anything else**: (1) a **stored-XSS chain** in the blog pipeline — `blog-article.mjs` injects Outrank `content_html` verbatim with no sanitization, gated only by a plaintext bearer token with no HMAC/replay protection; (2) **duplicated/templated review schema across all 29 city pages** — a 12-review pool recycled under city-specific "{City} Customer Reviews" headings, which is exactly the self-serving review markup the 2026-06-16 compliance pass was supposed to remove (the fix missed `_build/template.html`); and (3) **layout-shift/payload risk from the markdown image renderer**, which emits bare `<img>` tags (no dimensions, no lazy, no webp) on 150+ placements. The dominant theme is **generator/template drift**: a handful of shared templates and partials in `_build/` propagate the same defect to 250+ pages at once — meaning each fix is one source edit plus a rebuild. Lower-priority work (title/description length, contrast, heading skips, link hygiene) is real but cosmetic. **The XSS chain is the only finding with security impact and should be fixed first.**

## 4. Themes / Systemic Patterns

- **Generator/template drift is the dominant pattern.** Five of the top findings originate in shared `_build/` artifacts and fan out to hundreds of pages: the review block (`template.html:139-162` → 29 pages), the missing `<main>` + dead skip link (5 generators + `nav.html.j2` → 257 pages), the long-title suffix (`generate_product_pages.py:336` → 95 pages), the bare markdown images (`overrides_loader.py:113` → 150+ placements), and the package heading skip (`package_template.html` → 9 pages). **Each is one source edit + rebuild.**
- **Incomplete compliance migration.** The 2026-06-16 review-schema removal (commit `01d12b9`) only patched `sku_template.html`; `template.html` (cities) was never touched — a config-vs-reality drift between stated policy and shipped markup.
- **Templates leaking into the publish dir.** `site/blog/_template.html` ships indexable; the canonical pattern is "templates live in `_build/`."
- **Trust-the-webhook anti-pattern.** The blog function trusts Outrank's payload end-to-end (weak auth + no sanitization), turning a publishing integration into a same-origin code-execution surface.
- **Image pipeline has a gap, not an absence.** Card/hero templated images are correctly sized/lazy/webp; only the **markdown override path** and **7 EcoFlow product heroes** fall through — a localized hole, not a sitewide failure.
- **Data-consistency drift in hand-authored pages** (marquee geo, blog vs package pricing) — values baked into individual HTML that diverge from `_build/site_constants.json` / canonical product pages.

All HIGH/MEDIUM findings were **exhaustively, mechanically verified** across all ~297 `site/` HTML pages (grep/Python/jsdom passes on review-schema, skip-link/`<main>`, titles, images, geo, schema shapes) and via real `render()`/code reads of the Netlify functions; the only items requiring **external human verification** are the wedding-venue blog facts (capacities, the Horizons→Mintara rename, phone 604-777-5111, permit/insurance terms) and a live re-check of the **Outrank webhook-signing options** before choosing the HMAC vs. timing-safe-bearer hardening path.
